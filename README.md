# Audio Visualizer

Vite + React + TypeScript 기반의 오디오 리액티브 비주얼라이저 프로젝트입니다.

## 실행 방법

```bash
npm install
npm run dev
```

빌드:

```bash
npm run build
```

프리뷰:

```bash
npm run preview
```

## 사용 방법 요약

1. 오디오 파일을 업로드하거나 드래그 & 드롭합니다.
2. Play 버튼을 눌러 재생합니다.
3. 좌측 패널에서 프리셋을 클릭하여 실시간으로 전환합니다.
4. 녹화를 시작한 뒤 원하는 구간에서 정지하면 webm 파일이 다운로드됩니다.
